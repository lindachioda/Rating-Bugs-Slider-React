# 🐞 Insect Review Slider

A guided React exercise featuring an interactive insect review slider. The project displays insect reviews with dynamic star ratings generated using `Array.from()` and manages the slider state with React's `useState` hook.

## ✨ Features

- Browse insect reviews using navigation buttons.
- Display dynamic star ratings.
- Generate star elements with `Array.from()`.
- Manage the active review using `useState`.
- Create an interactive and responsive user interface.
